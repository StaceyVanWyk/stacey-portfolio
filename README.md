# Stacey Van Wyk | Personal Portfolio

A personal portfolio website showcasing my software development journey,
technical skills, projects, education and professional experience.

## About the Project

This website was built from scratch using HTML and CSS as part of my
continued development as a software developer.

The goal of the project is to create a simple, professional and responsive
